# Reference Systems (Benign)

These are candidate codebases or protocols to adapt for transport, consensus,
and workflow concepts. This project does not use or adapt malicious tooling.

## Mesh and Gossip
- libp2p (mesh networking, gossip)
- NATS (pubsub)

## Task and Workflow
- Temporal (durable workflows)
- Redis Streams (consumer groups)

## Leases and Coordination
- etcd or Consul (leases, leader election)
